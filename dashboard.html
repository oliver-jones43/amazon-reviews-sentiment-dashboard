Method. Three-class ground truth from rating — 4–5 → positive · 3 → neutral · 1–2 → negative. The model never saw the rating; verdict from title + text only.
Sampling. Balanced ≈50 per class, seeded (42) from the full 152,410-review file, so the rarer ★3 class is fairly represented instead of under-covered in read-order.
Emotion methods. LLM: single primary emotion from the 8. NRC: sum of lexicon word-scores per emotion, argmax is the answer.
Reskin. Theme lives in the CSS token block — edit --bg/--pos/--neg/--acc, etc. to recolor.
